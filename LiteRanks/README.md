# LiteRanks — Небесная Империя

**Версия:** 1.0.0  
**Ядро:** LiteCore v1.0.9  
**API:** PocketMine-MP 3.0.0 — 3.0.1  
**PHP:** 8.0

## Описание

Плагины серии «Небесная Империя» объединяют регистрацию, авторизацию и систему донат-рангов в едином визуальном стиле. LiteRanks отвечает за иерархию привилегий, форматирует чат и nameTag каждого игрока согласно его рангу.

## Архитектура

- **Ранги живут в `config.yml`** (не в БД). В MySQL хранится только привязка игрока: `rank_id` + `display_rank_id`.
- Переименовал/перекрасил ранг в конфиге — все игроки обновляются мгновенно, без миграций.
- Нет рассинхрона между конфигами и базой.
- `softdepend: [LiteRegister]` — работает и без него.

## Установка

1. Скопируйте папку `LiteRanks/` в `plugins/` вашего сервера.
2. Заполните `database` в `resources/config.yml` (host, user, password, name).
3. Перезапустите сервер или выполните `/plugin reload`.

## Команды

### Игрок

| Команда | Описание |
|---------|----------|
| `/prefix` | Показать список доступных печатей |
| `/prefix <номер>` | Выбрать печать (цифрой) |
| `/prefix reset` | Сбросить печать на текущий ранг |
| `/myrank` | Показать свой ранг и печать |

### Админ (право `lc.ranks.admin`)

| Команда | Описание |
|---------|----------|
| `/rank give <ник> <ранг> [время]` | Пожаловать ранг (опц. срок: `30m`, `7d`, `365d`, `1y`) |
| `/rank set <ник> <ранг>` | Сменить ранг без срока |
| `/rank remove <ник>` | Снять ранг → дефолтный |
| `/rank list` | Все ранги сервера |
| `/rank info <ранг>` | Информация о ранге |

## Права

| Право | Описание |
|-------|----------|
| `lc.ranks.prefix` | `/prefix` (по умолчанию: все) |
| `lc.ranks.myrank` | `/myrank` (по умолчанию: все) |
| `lc.ranks.admin` | Админ-команды (`/rank *`) (по умолчанию: OP) |

## Чат

Формат сообщения:
```
§8[Печать§8] §fНик §8» §7текст
```

Пример:
```
[§6Принц§8] §fИгрок §8» §7Привет, всем!
```

## NameTag

Над головой игрока отображается:
```
§8[Печать§8] §fНик
```

## Настройка рангов

Все ранги находятся в секции `ranks:` файла `resources/config.yml`:

```yaml
ranks:
  strannik:
    display: "Странник"      # Русское название
    weight: 1                 # Вес: чем больше — тем выше ранг
    color: "§7"              # Цвет префикса
    prefix: "Странник"       # Текст печати (без цвета рамки §8[..§8])
    permissions: []          # Узлы прав (поддержка "*" и "a.b.*")
    limits: {}               # Лимиты для будущих плагинов (homes, fly и т.д.)
```

### Ключевые поля

- **`weight`** — определяет иерархию. Игрок с `weight: 5` может выбрать печать любого ранга с `weight ≤ 5`.
- **`permissions`** — узлы прав. `*` даёт все права. `ranks.kit.*` покрывает `ranks.kit.daily`.
- **`limits`** — произвольные лимиты для интеграции с другими плагинами (home-слоты, полёт, киты и т.д.).

### Добавление нового ранга

1. Откройте `resources/config.yml`.
2. Добавьте блок ранга в секцию `ranks:`.
3. Перезагрузите плагин `/plugin reload`.

Новые игроки автоматически получат ранг из `settings.default-rank`.

## База данных

Таблица: `lc_player_ranks`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT AI PK | Автоинкремент |
| `username` | VARCHAR(16) | Ник игрока (UNIQUE) |
| `rank_id` | VARCHAR(32) | ID текущего ранга |
| `display_rank_id` | VARCHAR(32) | ID отображаемой печати (NULL = как rank_id) |
| `granted_by` | VARCHAR(16) | Кто выдал (ник или CONSOLE) |
| `granted_at` | DATETIME | Дата выдачи |
| `expires_at` | DATETIME | Срок действия (NULL = навсегда) |

## Логирование

Логи раздачи рангов сохраняются в `plugins/LiteRanks/logs/YYYY-MM-DD.log`.

## Известные ограничения

- Нет GUI-форм (LiteCore не содержит `pocketmine\form\*`).
- Выбор печати — текстовый список с вводом цифры из чата.
- Движение блокируется через `PlayerMoveEvent::setCancelled(true)` (нет `setImmobile()`).
- Звуков нет — только чат и title.
