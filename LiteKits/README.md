# LiteKits — Небесная Империя

**Версия:** 1.0.0  
**Ядро:** LiteCore v1.0.9  
**API:** PocketMine-MP 3.0.0 — 3.0.1  
**PHP:** 8.0  
**Игра:** Minecraft Bedrock 1.1.5 (Discovery Update)

## Описание

Третий плагин серии «Небесная Империя». Система китов, привязанная к весам рангов из LiteRanks: кит с номером N доступен игроку, если вес его ранга **≥ N**.

- Ранг 1 (Странник) → доступен только кит `/kit 1`
- Ранг 3 (Воин) → доступны киты 1–3
- Ранг 10 (Небесный Дракон) → доступны все киты 1–10

## Установка

1. Скопируйте папку `LiteKits/` в `plugins/` сервера.
2. Проверьте `database` в `resources/config.yml`.
3. Перезапустите сервер.
4. В консоли появится:
   - `✓ База данных готова (префикс: lc_)`
   - `✓ Загружено 10 кит(ов) из config.yml`
   - `✓ LiteRanks найден — доступ к китам по весу ранга`

## Команды

| Команда | Описание |
|---------|----------|
| `/kit` | Текстовое меню: все киты, статус, кулдаун |
| `/kit <номер>` | Получить кит (если вес ранга позволяет и КД готов) |
| `/kit help` | Краткая справка |

## Права

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `lc.kits.use` | Использование `/kit` | все |
| `lc.kits.admin` | Обход кулдауна и веса ранга | OP |

## Кулдаун

**5 часов на каждый кит отдельно** (не общий). После `/kit 3` кит 3 недоступен 5 часов, но киты 1–2 — можно, если их КД готов. Хранится в БД `lc_kits_cooldowns`.

Администраторы (`lc.kits.admin`) обходят кулдаун полностью.

## Интеграция с LiteRanks

- Доступ по весу: `KitManager::playerWeight()` читает ранг через публичный API LiteRanks (`Main::rm()->getRankOf($nick)->weight`).
- Если LiteRanks не найден: `WARNING` в лог, киты доступны **только** с правом `lc.kits.admin`.
- `softdepend: [LiteRanks, LiteRegister]` — LiteKits загрузится даже без них.

## База данных

Таблица `lc_kits_cooldowns` (создаётся автоматически):

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT AI PK | Автоинкремент |
| `username` | VARCHAR(16) | Ник игрока |
| `kit_id` | INT | Номер кита (1–10) |
| `last_used` | DATETIME | Когда последний раз брал |
| | UNIQUE | `(username, kit_id)` |

## Настройка китов

Все киты — в `resources/config.yml`, секция `kits:`. Каждый кит:

```yaml
kits:
  3:
    name: "Воин"
    color: "§a"
    icon: "⚔"
    weight: 3          # требуемый вес ранга
    cooldown: 18000    # сек (5 часов)
    items:
      - { id: 276, count: 1, ench: { 9: 2 } }  # алмазный меч, Острота II
```

- `id` предмета — числовой (ItemIds ядра).
- `ench: {ID: уровень}` — зачарования.
- `meta:` — вариация (по умолчанию 0).
- `name:` — кастомное имя (необязательно).
